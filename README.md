# 🍽️ Swiggy Sales Analytics Project  

## 📌 Project Overview  
This project focuses on analyzing Swiggy sales data using SQL Server and Power BI to generate meaningful business insights.  

The objective of this project is to analyze sales performance, customer behavior, restaurant trends, and revenue patterns to support data-driven decision-making.

All data processing and analysis were performed using SQL Server, and interactive dashboards were created in Power BI.

---

## 🎯 Objectives  

- Analyze overall sales and revenue performance  
- Identify top-performing restaurants and cuisines  
- Understand customer ordering patterns  
- Discover peak order times and busiest days  
- Track monthly and yearly revenue trends  
- Build an interactive dashboard for business insights  

---

## 🛠️ Tools & Technologies Used  

- Microsoft SQL Server  
- SQL (Joins, CTEs, Subqueries, Aggregations, Window Functions)  
- Power BI  
- DAX (Data Analysis Expressions)
